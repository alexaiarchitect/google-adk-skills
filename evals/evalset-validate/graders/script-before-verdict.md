The verdict has to come from running the validator, not from reading the file and
recognising the rule. `tool_order` compares *tool calls*, so the expressible form
of "run the script before you pronounce" is: the skill fired, and then its script
ran. The final message necessarily follows both.

Pairs with `criteria.md`, which fails an answer given without validating
anything.
